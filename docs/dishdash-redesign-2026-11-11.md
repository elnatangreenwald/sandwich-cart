# TEN-WICH UI/UX Redesign — DishDash Inspired
## Date: 11.11.2026

## Overview

Complete visual redesign of the TEN-WICH mobile food ordering application, inspired by the DishDash Dribbble design by Nika Ejibia.

## Design Philosophy

### Primary Inspiration: DishDash
- Bold orange & yellow identity
- Large rounded shapes (20-36px radii)
- Strong visual hierarchy
- Clean white content cards
- Playful food imagery
- Energetic, youthful, appetizing feel

### Secondary Reference: TEN-WICH Brand
- Original logo preserved
- Brand personality maintained
- Hebrew RTL layout perfect

## Color System

| Token | HEX | Usage |
|-------|-----|-------|
| Primary Orange | `#F5381E` | Main brand, active states |
| Coral Orange | `#F94F2A` | Promotional cards, accents |
| Golden Yellow | `#F89913` | Hero areas, highlights |
| Soft Peach | `#F8A758` | Background decorations |
| Warm White | `#FAFAFB` | Content surfaces |
| Dark Navy | `#062D39` | Primary typography |
| Lime Green | `#B6DE70` | TEN-WICH accents |
| Turquoise | `#20C4CC` | Interactive accents |
| Success | `#22C55E` | Confirmations |

### Color Balance
- ~40% warm white/light backgrounds
- ~25% orange and coral
- ~15% yellow and peach
- ~15% navy typography
- ~5% lime/turquoise accents

## Typography

- **Font**: Rubik (Hebrew-optimized)
- **Hero Titles**: 32px, ExtraBold
- **Screen Titles**: 24px, Bold
- **Section Titles**: 22px, Bold
- **Product Names**: 17px, Bold
- **Body**: 15-16px, Regular
- **Labels**: 13-14px, Medium

## Component Styling

### Cards
- White backgrounds
- 22-28px border radius
- Subtle shadows
- Generous padding

### Buttons
- Pill/rounded corners
- 54px min height
- Orange/yellow gradients
- Strong shadows

### Product Options
- 3px borders
- Green checkmarks
- Scale animations on selection

### Category Switches
- Horizontal scrolling
- Yellow/orange selected state
- Shadow elevation

## Layout Structure

### Header
- Sticky positioning
- Logo + pill button
- Transparent background (over gradient)

### Hero
- Golden yellow gradient background
- Floating food emojis
- Bold typography with gradient text

### Content
- Warm white background
- White cards with shadows
- Generous spacing (16-24px gaps)

### Cart Bar
- Fixed bottom position
- Gradient fade background
- Large rounded orange button

## Animation

- Pop-in effects for elements
- Spring easing curves
- 200-400ms durations
- Reduced motion support
