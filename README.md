# 🥪 מערכת הזמנות לעגלת סנדוויצ'ים

מערכת הזמנות עם שני ממשקים:

| כתובת | למי | מכשיר |
|---|---|---|
| `/` | לקוחות שמזמינים | נייד |
| `/admin` | ניהול ההזמנות בעגלה | טאבלט |

כל הזמנה שנשלחת מהנייד מופיעה מיד בטאבלט (בלי לרענן), והלקוח רואה בזמן אמת מתי ההזמנה שלו מוכנה.

---

## ממשק הלקוח (`/`)

- **בונים סנדוויץ' ב-3 שלבים** עם תמונות:
  1. לחם (חובה, בחירה אחת): פיתה, לחמניה שמונה, לחם מחמצת
  2. ממרחים (אפשר כמה): פסטו, גבינת שמנת, חריף, מיונז
  3. מילוי (לא חובה, בחירה אחת): טונה, חביתה, שקשוקה, סביח
- **מחירים**: סנדוויץ' 10 ₪ (כולל הכול), שתייה (קולה / מים / סודה) 6 ₪, אייס קפה 8 ₪.
- **"הקבועים שלי" ⭐**: אפשר לשמור סנדוויץ' קבוע ולהוסיף אותו לסל בלחיצה אחת. נשמר בטלפון של הלקוח (localStorage), עד 8 קבועים.
- **סל**: שינוי כמויות, מחיר כולל מחושב אוטומטית.
- **פרטים בהזמנה**: שם, טלפון, הערות חופשיות, **ובעוד כמה דקות מגיעים לאסוף** (כפתורים מהירים 5–45 דק' או מספר מדויק). מוצגת שעת האיסוף המשוערת.
- השם והטלפון נשמרים בטלפון לפעם הבאה.
- **מסך מעקב חי** אחרי ההזמנה: מספר הזמנה, שלבים (התקבלה → בהכנה → מוכנה → נאספה), ספירה לאחור עד שעת ההגעה. כשההזמנה מוכנה הטלפון רוטט ויש קונפטי 🎉.
- אם הלקוח סוגר ופותח את הדף, מסך המעקב חוזר אוטומטית (לאותו יום). כפתור "ההזמנות שלי" מציג את כל ההזמנות שלו מהיום.
- פריט שסומן "אזל" בניהול מוצג אפור ואי אפשר לבחור אותו.
- התשלום בעת האיסוף.

## ממשק הניהול (`/admin`)

- **כניסה בסיסמה** (משתנה הסביבה `ADMIN_PASSWORD`). הטאבלט נשאר מחובר.
- **מסך "מתחילים משמרת"**: הלחיצה עליו מפעילה את צלילי ההתראה (דפדפנים חוסמים צליל בלי לחיצה) ומשאירה את המסך דולק (Wake Lock).
- **לוח הזמנות פעילות** בשלוש עמודות: 🆕 חדשות · 👨‍🍳 בהכנה · ✅ מוכנות לאיסוף.
  - הזמנה חדשה נכנסת מיד עם **צליל התראה**, הבהוב והודעה קופצת.
  - ההזמנות ממוינות לפי **מי מגיע ראשון**.
  - **אינדיקציית הגעה** בכל כרטיס: פס התקדמות וצבע. ירוק: יותר מ-10 דק'. כתום: 4–10 דק'. אדום: 3 דק' ומטה, או כשהלקוח כבר אמור להיות כאן.
  - **סימון כל פריט בנפרד** (✓) כדי לעקוב מה כבר הוכן בהזמנה.
  - כפתור אחד מקדם את ההזמנה לשלב הבא: "התחלת הכנה" → "מוכן" → "נאסף ושולם". אפשר גם לחזור שלב אחורה (↩) או לבטל (✕).
  - לחיצה על מספר הטלפון מחייגת ללקוח.
  - נקודה ירוקה ליד השם = מחובר בזמן אמת. אם החיבור נופל, הוא חוזר לבד ומסנכרן הזמנות שפוספסו.
- **הושלמו**: הזמנות שנאספו או בוטלו, עם אפשרות להחזיר הזמנה ללוח.
- **תפריט ומלאי**: מתג זמין/אזל לכל פריט, ועריכת מחיר הסנדוויץ' ומחירי השתייה. השינוי נשמר מיד ומופיע אצל הלקוחות.
- **סיכום יומי**: מספר הזמנות, מספר סנדוויצ'ים, כמה נגבה, סה"כ צפוי, ופילוח לפי לחם, מילוי, ממרח ושתייה (עוזר לדעת מה להכין מראש).

## שמירת נתונים

- **ההזמנות נשמרות ליום אחד בלבד** (לפי שעון ישראל). בחצות מתחיל יום חדש, המספור חוזר ל-1 וקובץ היום הקודם נמחק.
- ההזמנות נשמרות בקובץ `orders-YYYY-MM-DD.json` בתיקיית `DATA_DIR`, ומצב התפריט (זמינות ומחירים) בקובץ `menu.json`.
- הקבועים של הלקוח והסל שלו נשמרים רק בטלפון שלו.

## הרצה מקומית

```bash
npm install
npm start
```

אחר כך פותחים:
- לקוח: http://localhost:3000
- ניהול: http://localhost:3000/admin (סיסמת ברירת מחדל מקומית: `admin1234`)

## העלאה ל-Railway

1. מעלים את התיקייה ל-GitHub (קבצי `node_modules` ו-`data` לא עולים, הם ב-`.gitignore`).
2. ב-Railway: **New Project → Deploy from GitHub repo** ובוחרים את הריפו. Railway מזהה Node ומריץ `npm start` לבד.
3. בלשונית **Variables** מגדירים:

   | משתנה | חובה? | הסבר |
   |---|---|---|
   | `ADMIN_PASSWORD` | **כן** | הסיסמה לממשק הניהול. בלעדיו הסיסמה היא `admin1234` |
   | `SHOP_NAME` | לא | שם העגלה שמופיע למעלה (ברירת מחדל: "עגלת הסנדוויצ'ים") |
   | `DATA_DIR` | מומלץ | `/data`, יחד עם Volume (סעיף 4) |

4. **מומלץ מאוד: Volume.** ב-Railway: לחיצה ימנית על השירות → **Attach Volume**, נקודת עיגון `/data`, ומגדירים `DATA_DIR=/data`. בלי Volume, כל Deploy או ריסטארט מוחק את ההזמנות של היום ומחזיר את התפריט לברירת המחדל.
5. **Settings → Networking → Generate Domain** כדי לקבל כתובת ציבורית.
6. מומלץ להדפיס **QR** לכתובת הראשית ולהדביק על העגלה, ולפתוח בטאבלט את `/admin`.

> חשוב: להריץ **מופע אחד בלבד** (Replicas = 1). העדכונים בזמן אמת מנוהלים בזיכרון של השרת.

## מבנה הקוד

```
server.js            שרת Express: API, שמירה יומית, עדכונים בזמן אמת (SSE)
defaultMenu.js       התפריט: מוצרים, מחירים ותמונות
public/
  index.html         ממשק הלקוח
  app.js             לוגיקת הלקוח: בונה סנדוויץ', סל, קבועים, מעקב
  styles.css         עיצוב הלקוח (Glassmorphism)
  img/               תמונות המוצרים (webp)
  admin/
    index.html       ממשק הניהול
    admin.js         לוח הזמנות, צלילים, תפריט, סיכום
    admin.css        עיצוב הניהול
```

### API

| Method | נתיב | הרשאה | תיאור |
|---|---|---|---|
| GET | `/api/menu` | — | תפריט ושם העגלה |
| POST | `/api/orders` | — | יצירת הזמנה (המחיר מחושב בשרת) |
| GET | `/api/orders/:id` | — | מצב הזמנה |
| GET | `/api/orders/:id/stream` | — | עדכונים חיים להזמנה (SSE) |
| POST | `/api/admin/login` | — | כניסה, מחזיר token |
| GET | `/api/admin/orders` | admin | כל ההזמנות של היום |
| GET | `/api/admin/stream?token=` | admin | עדכונים חיים לניהול (SSE) |
| PATCH | `/api/admin/orders/:id` | admin | שינוי סטטוס (`new`/`preparing`/`ready`/`picked_up`/`cancelled`) |
| PATCH | `/api/admin/orders/:id/items/:index` | admin | סימון פריט כבוצע |
| PUT | `/api/admin/menu` | admin | עדכון זמינות ומחירים |

### הוספה או שינוי של מוצר

עורכים את `defaultMenu.js` (שם, `id` ייחודי, תמונה ב-`public/img`) ומעלים מחדש. זמינות ומחירים ששונו מממשק הניהול נשמרים גם אחרי העדכון.

### אבטחה

- המחיר תמיד מחושב בשרת, הלקוח לא יכול לשנות אותו.
- הגבלת קצב: עד 30 הזמנות ל-10 דקות מאותה כתובת IP, ועד 10 ניסיונות כניסה לניהול.
- כל טקסט שהלקוח מזין מוצג בצורה בטוחה (escaped) בממשק הניהול.
